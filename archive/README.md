# Immutable historical research archive

This area contains **byte-for-byte copies of the original available files** from the ChatGPT workspace and uploaded research packages, even when files are superseded, duplicated, or represent failed setup attempts. Original archive bytes are not reformatted, silently corrected, or overwritten. Extracted copies are for convenient browsing and are indexed individually.

The upload/source origin of a filename is not proof that every notebook was executed. Inspect original output manifests and run logs for execution status. Before public redistribution, check any third-party dataset, licensed model artifact, embedded credentials, personal information, or restricted benchmark material.

Original file hashes and ZIP-member hashes are recorded in `../evidence/`.
