# Original research workspaces (additional available source files)

These are byte-preserved copies of available non-ZIP workspace folders, including early result directories, local rendered charts, first/second-pass rerun ZIPs, preliminary reports and externally attached work directories. Their original folder name and SHA256 are recorded in `evidence/master_workspace_file_registry.csv`.

These files may duplicate later release archives; they are intentionally retained to document original research history and failure corrections. An upload-folder name does not prove run authenticity; refer to actual run receipts.
