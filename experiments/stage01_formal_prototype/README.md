# Stage 1 — Contract specifications and acceptance fixtures

## Scientific scope
The initial formal prototype defined task contracts, probe schemas, observations, certificates, and acceptance fixtures. This is design-and-test work, not model-driven agent evaluation.

## Original evidence source
`AURA_Stage1_Schema_and_Test_Pack_v1.zip`. The file exists byte-preserved beneath `archive/`; its extracted members appear under experiment-specific `raw/` or `prototype/` paths when applicable. Find exact paths and SHA256 digests in `evidence/master_source_registry.csv` and `evidence/master_archive_member_registry.csv`.

## How to inspect or reproduce
Read the original schema pack, specification report and validation fixtures. No numerical result should be inferred beyond recorded acceptance results.

## Data labels and limitations
- An execution record is not the same as a test, benchmark calibration, planner world, or certificate replay.
- Keep FAIL, UNCERTAIN, skipped or interrupted cases rather than excluding them.
- Do not claim that all experiments were executed in one environment.
- Cite the archived original outputs, not handwritten summaries, in publication figures.
